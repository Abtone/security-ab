# security-amanda.blanco

Sitio estático para publicar el CV público en GitHub Pages.

El repositorio publica solo la version HTML. El PDF se genera desde el boton `Exportar PDF` del navegador cuando sea necesario.

La version en espanol esta en la raiz del sitio y la version en ingles esta en `/en/`.

Configuración recomendada en GitHub:

- Source: Deploy from a branch
- Branch: main
- Folder: /root
